# TRAE宝表情工厂 · TRAE Emoji Studio

> 为「TRAE宝」打造的可交互表情包生成器：调表情、换姿势、摆骨骼、捏体型、换配色、配背景、加文案、叠贴纸、加循环动画，
> 实时预览并导出 1:1 的 PNG 表情图与 GIF 动图。
> 基于活动《TRAE宝表情包小赛 · 下一套官方表情包，由你来画》的角色三特征（方形头部 / 屏幕表情 / 黑色机身）与自绘参考图开发。

- 纯前端单页应用：无框架、无构建步骤、无网络依赖
- 素材 base64 内嵌，双击 `index.html` 即可离线运行
- 全部处理在浏览器本地完成，不上传任何数据

---

## 一、快速开始

| 方式 | 操作 | 说明 |
|---|---|---|
| 直接打开（推荐） | 双击 `04-表情生成器-emoji-generator/index.html` | 素材已内嵌，离线可用 |
| 启动脚本 | 双击 `04-表情生成器-emoji-generator/启动网站-start.bat` | 自动起本地服务并打开浏览器 |
| 命令行 | 在该目录执行 `python -m http.server 8923`，访问 `http://127.0.0.1:8923/` | 复制到剪贴板等能力在 http 下更稳定 |

浏览器要求：Chrome / Edge / Firefox / Safari 等现代浏览器（需支持 Canvas 2D 与 ES5+）。
建议分辨率 ≥ 1200px 宽以获得双栏布局；≤ 920px 自动切换为单栏 + 吸顶预览。

## 三、使用指南

1. **姿势**：点选 10 款姿势卡片；改变姿势会覆盖当前骨骼角度。
2. **表情**：点选任意表情即时贴到屏幕；滑动到列表末尾点「自己画」打开像素画板。
   - 画板工具：✏️ 画笔 / ◻ 橡皮 / 🪣 填充 / 💧 吸管 / 1·2·3px 笔刷 / 左右对称开关；
   - 配色：20 色预设色板 + 🎨 自定义颜色（系统调色板）+ 🖥 屏幕取色（EyeDropper，可在屏幕任意位置吸色），
     当前颜色以色点 + HEX 显示；吸管单击画板已有像素即可取色并自动切回画笔；
   - 辅助：↶ 撤销（Ctrl+Z）/ 清空 / 套用「平常心」底稿；
   - 侧栏：名称（≤8 字）、发光色、眼睛亮度（40%~160%）、实时预览、保存并使用；
   - **每张表情卡片右上角都有 ✎ 角标**：内置表情点开即二次创作（以原像素为底稿，可改名 / 调亮度 / 改像素），
     保存后角标转金色常亮；编辑器内「↺ 还原官方表情」可一键恢复。自定义表情点开则可继续编辑或删除。
3. **骨骼**：拖动 13 个滑杆微调关节，或在预览画布上直接拖动——空白处左右拖动 = 连续 360° 转身，
   上下拖动 = 轻微前倾 / 后仰（方向与鼠标一致，±25° 内不翻倒）；
   按住手 / 脚 / 头 = IK 反解关节（滑杆数值自动同步回填）；「关节归零」一键复位。
4. **部位**：在「部位」页选择头 / 颈 / 躯干 / 左右上臂 / 左右前臂 / 左右手 / 左右腿 / 左右脚，
   或直接单击画布部位；用 7 个滑杆调整整体尺寸、局部 XYZ 旋转与位移。父级调整会带动子级，
   切换姿势保留部位参数；可复位当前部位或全部位，选中高亮不会进入导出。
5. **体型**：在「体型」页点选预设（官方标准为默认档）或点「🎲 随机体型」；也可以用 10 条比例滑杆捏体型
   （头宽高深、屏幕占比、躯干宽长、四肢粗细、臂长、腿长、脚掌长），肩 / 髋 / 颈关节位置自动联动，
   超高体型自动缩小取景保证全身入画；「↺ 还原官方标准体型」一键复位。给当前体型起个名字可保存进
   「我的体型」（点击应用 / ✕ 删除），支持导出 JSON 分享与导入；体型存本机，导出图与缩略图都使用当前体型。
6. **配色**：点选配色预设整套换色，或用「全局色板」取一个基准色自动派生全身；
   也可以对头 / 躯干 / 手臂 / 腿 / 屏幕边框单独取色微调，随时「↺ 还原官方配色」。
7. **背景**：13 款一键切换，「透明」用于表情包投稿；也可以「选择图片」上传本地图作背景，
   选显示方式（填充 / 适应 / 平铺）并拖动位置滑杆微调；图片最长边自动压到 1024 并存在本机浏览器。
8. **文字**：输入文案或点选预设 → 选位置 / 样式 / 颜色 / 字号。
9. **贴纸**：点选内置贴纸即往画布加一张；「上传图片」或「自己画」可添加自定义贴纸。
   选中后可直接在预览画布拖动，用滑杆调位置 / 大小 / 旋转，用「上移 / 下移 / 置顶 / 置底」排层级，
   「删除这张 / 清空全部」收尾；Delete / Esc 可快速删除或取消选中。
10. **套系 / 随机**：点「一键套系」快速出成套表情；点「🎲 随机灵感」探索组合。
11. **动画**：默认处于暂停态，在「动画」页调呼吸起伏 / 左右摇摆 / 四肢摆动（走路式）/ 循环周期后，
   点「▶ 播放预览」才开始循环；勾选「眨眼闪现」后每个周期末短促眨一下眼（第二表情可换任意表情做趣味闪现）；
   「⏸ 暂停预览」只停预览播放，GIF 导出不受影响；播放循环动画会自动退出关键帧查看（两套动画互斥）。
12. **动作（关键帧）**：在「动作」页把骨骼姿势串成连续动作——
   - 直接点动作预设（招手 / 点头 / 摇头 / 开心跳 / 左右看 / 扭腰摇摆 / 举手欢呼）即载入 5 帧时间轴；
   - 或在「骨骼」页摆好姿势 → 回「动作」页点「＋ 打关键帧」，重复几次即成自制动作；
   - 拖动播放头可预览任意时刻的插值姿势，⏹ 回到骨骼退出查看；每帧可「载入到骨骼」微调后「⟳ 更新」；
   - **多段串联**：下拉选择任意预设或「我的动作」点「⤵ 追加到末尾」，衔接处自动留 0.4s 平滑过渡；
   - 时间轴可命名保存进「我的动作」（12 套），支持导出 JSON 分享与导入；
   - 「重置」清空时间轴（动作库保留），时间轴存本机、刷新恢复。
13. **导出**：选尺寸 → 「⬇ 下载表情」/「⧉ 复制图片」/「📦 导出套系（8 张）」/「🎬 导出 GIF」；
   有关键帧动作时 GIF / 🖼 APNG 均按时间轴循环采样（12fps、8~48 帧），无关键帧时 GIF 保持循环动画 16 帧；
   APNG 为全彩无损动图（像素表情无色量化损失）。

## 五、角色还原要点

| 部位 | 建模约定 |
|---|---|
| **头部** | 整块长方体，宽 : 高 : 深 ≈ 1 : 0.854 : 0.908；头部角部**缺一块**（宽 ≈ 0.11W / 高 ≈ 0.12H / 深 ≈ 0.17D），用 3 块盒体拼成 L 形，缺口后壁贴阴影片（v1.6.0：铺满开口、按头色 ×.86 压暗，不再留亮边）；拼块用内部描边消除接缝，整体仍读作「一整块」 |
| **屏幕（面部）** | 凸出式装配件（v1.6.2 起：有厚度的边框框条 + 内缩的深色玻璃实体）：边框为凸出前脸 12、纵深 26（`bezelDepth`，v1.7.1 由 20 加深，向头部内侧多嵌 6 保证贴合）的四条框条，玻璃是外廓再内缩 3（`glassInset`）、纵深 34 的深色实体且前表面再内凹 4，正 / 侧 / 顶视都有可见台阶；侧视角读到「浅色边框包着深色屏体」的实体断面，90° 前后边框仍由侧壁成条可见，不会随投影面积归零而消失；屏幕方框按「占用脸部区域」布局，凸出的板面与缺口错位，**不会遮挡头部缺角**；v1.7.3 起边框与玻璃改用面色描边，与头前脸的交界不再有深色暗线；v1.7.4 玻璃纵深 34 → 22，与边框后缘齐平，斜视角不再露出深色玻璃侧壁（那条被读成「缝」的暗带） |
| **坐标与骨骼** | 原骨骼为 MC 式简化骨架：躯干 → 头 / 双臂 / 双腿，肩 / 髋驱动肢段整体摆动；v1.7 新增颈部与左右前臂局部节点，默认仍保持单段外观；腿部髋关节支持前后摆 + 侧摆两自由度 |
| **体型** | 官方标准体型为默认档（几何 = 官方基准 × 全 1 比例，逐字段等于 v1.7.4 实测值）；10 项比例可调，关节位置随躯干 / 头自动联动，屏幕占比受缺角约束收口；边框 / 玻璃 / 缺角等结构特征件不随体型缩放；超高体型自动缩小取景（官方构图锚定头顶） |
| **光照与配色** | 默认官方炭灰（头 `#373834` / 躯干 `#2d2e2b` / 腿 `#2f302d`）；高环境光 + 弱方向光，拟合官方全景图四视角亮度。配色可整体或按部位替换，明暗随基色自动换算 |

## 六、技术实现

1. **像素表情系统**：40×28 网格 + 像素原语（菱形眼 / 弧线 / 爱心 / 星形 / 螺旋 / 汗滴…）；
   `imageSmoothingEnabled = false` 放大保持硬边，`shadowBlur` 双通道叠加做 LED 辉光。
   自定义表情是**纯数据**：`{ id, label, glow, bright, cells[40×28] }`（空串 = 透明），
   `customDef()` 把 cells 包装成与内置表情同构的 `draw(p)`，缓存 / 缩略图 / 3D 贴图 / 导出全链路复用同一套代码。
   v1.9.0 起内置表情也能二次创作：覆盖记录存 `traeEmoji.faceEdit.v1`（保持原 id，未改动时走官方原画），
   亮度 `bright` 在 `getFaceCanvas` 缓存位图里乘系数、辉光色按同一系数换算，渲染链路与自定义表情完全一致。
2. **3D 渲染管线**（`renderProcedural`）：世界坐标 y 向下、透视相机在 +z；
   每帧算世界矩阵 → 6 面背剔 + 朗伯光照 → 画家算法排序（排序键 = 该面四角的**最近点 z**，
   v1.6.0 由面中心 z 改，避免大面压住贴近它的近侧面）→ 屏幕作为特殊面用双三角形透视纹理映射贴表情，随头部转动。
   v1.6.1：屏幕可见性改用**屏幕空间投影有向面积**判定（点积判据会把「头不在相机光轴上」算进去，转角大就误判背面）；
   屏幕装配件盒体带 `front` 排序台阶（边框框条 1 / 玻璃实体 0.6），排序键下限取头正面最近点 z（否则大四边形头正面会吞掉贴在其上的边框与玻璃）；
   v1.6.2 起边框改为**有纵深 26 的框条**（`bezelDepth`）、玻璃外廓内缩 3（`glassInset`），
   侧视角由框条侧壁提供可见面——薄板在 90° 必然投影为线而消失。
   v1.7.1：**法线先归一化**（部位缩放会等比放大法线长度，`dot` 阈值随之失真，放大部件整块被误剔成背面）；
   `dot` 落在 0~0.05 的临界薄面再用**投影有向面积**兜底（`< 2 px²` 才剔除），角色面与道具面同口径；
   填充后按面色外扩约 0.75px 描边，填平斜视角相邻面的亚像素拼合缝。
3. **场景道具**：敲键盘附加「桌子 + 笔记本」、骑马附加「马」，以恒等矩阵（世界坐标）渲染，不随骨骼转动，
   与角色面统一进入排序，保证遮挡正确。
4. **导出**：离屏 canvas 按目标尺寸重绘 → `toBlob` 下载 / `ClipboardItem` 复制 / 批量循环出 8 张。
5. **自由贴纸**：贴纸是**实例数组** `{ uid, t, ref/src, x, y, scale, rot }`，数组顺序即层级；
   位置用画布百分比、`unit = 目标尺寸 / 1024` 统一缩放，预览 / 缩略图 / 导出共用 `drawStickerCore`，
   因此 1024 / 720 / 480 三档构图一致。选中框只画在预览层（`render(ctx, s, ui)` 的 `ui` 开关），导出不含。
   命中检测把点击点反向旋转到贴纸本地坐标后按包围盒判断，与透明区域无关、拖拽手感稳定。
6. **肢体拖拽 IK**：手 / 脚手柄 = 关节链端点的屏幕投影（正运动学与渲染骨骼同构），
   拖动时在屏幕空间做数值反解——11×11 粗网格 + 7 轮局部细化，代价函数带角度锚定项（抓取瞬间不跳角）；
   头部手柄为朝向增量。解出的角度直接写回骨骼状态，与 13 个滑杆共用同一份数据、天然同步；
   手柄高亮只画预览层（`ui` 开关），导出不含。
7. **指定部位调整**（v1.7.0）：状态 `S.parts` 保存 8 类 / 13 个左右实例的 `{ scale, rx, ry, rz, x, y, z }`，
   `updateSkeletonMatrices` 在原骨骼矩阵后叠加局部 `T × R × S`，父级自然带动子级，IK 与渲染共用同一矩阵。
   单击 / 拖动以 5px 阈值分流；命中使用主预览的投影面缓存，选中轮廓只在 `ui=true` 时绘制。
   颈部使用不绘制的连接代理；前臂静止时仍绘制原始整臂、以代理区分点选，调整时才切换分段实体，保证默认外观不变。
8. **外壳配色**：状态为 `S.skin = { head, torso, arm, leg, bezel }`，`buildSkeleton` 直接读取；
   全局色板按官方明度比例派生（躯干 .82 / 手臂 1.04 / 腿 .86 / 边框 .92，v1.12.0 手臂由 .80 提到 1.04，与躯干同屏也能读出轮廓），
   手 / 脚在此基础上略提亮（×1.16 / ×1.19），缺口阴影按头色压暗（×.86，v1.6.0 由 ×.78 收窄），**手 / 脚 / 阴影永不脱离基色**。
   光照拟合随基色自适应：`shadeHex` 在基色偏亮时按峰值等比压缩亮度系数，浅色外壳也保留正 / 侧 / 顶层次；
   屏幕玻璃与像素表情固定深色，不参与换色。配色写入 localStorage（`traeEmoji.skin.v1`），
   姿势缩略图按 160ms 防抖随配色重建（拖动取色时不逐帧重算 10 张缩略图）。
9. **全身塑形**（`BODY_BASE` / `BODY_REST` / `applyBody` / `fitCamera`，v1.8.0）：
   几何 = 官方实测基准 × 十项体型比例，`applyBody` 派生写入 `GEO3D`（骨骼 / 渲染 / IK / 缩略图全链路只读它）。
   派生公式在比例全为 1 时只做 ×1 与 ±0 运算，官方档逐字段等于旧硬编码值（像素级不变的构造性保证）；
   关节位置按官方关系联动（肩 = 躯干半宽 + 臂半宽 + 11、髋 = 躯干半高 - 7、颈咬合 5.5），
   屏幕占比受缺角硬约束收口；`fitCamera` 以官方构图的头顶 / 脚底投影为锚点，超高体型等比缩放取景、
   头顶锚定，官方与矮小体型构图不动。体型与保存列表存 localStorage（`traeEmoji.body.v1` / `bodySaved.v1`），
   导入比例一律按滑杆范围钳制；调试入口新增 `__traeEmoji.body`。
10. **关键帧动画（`KF` / `kfRigAt` / `renderKfView` / `startKfLoop`，v1.11.0）**：
   关键帧 = `{ t, rig }`（14 项骨骼角度全量快照），相邻帧逐字段 lerp × smoothstep 插值，
   循环时长 = 末帧 − 首帧；播放 / 播放头查看全部走 `renderKfView`（与循环动画共用渲染链路，
   `LAST_SK` 同帧更新 → 挂载贴纸逐帧联动），**不写入 `S.rig`**——渲染优先级：
   关键帧播放 > 播放头停留 > 循环动画 > 当前骨骼静态，两套动画互斥（播放一方自动暂停另一方，
   切离「动作」页或拖动身体 / 肢体即退出时间轴查看，骨骼编辑始终即时可见）。
   多段串联 = 关键帧整体平移接在末尾（+0.4s 过渡缓冲，衔接平滑收拢）；
   导出按 12fps 采样（8~48 帧钳制），GIF 走既有 `TraeGif`，APNG 走新增 `TraeApng`：
   逐帧 `canvas.toBlob` 提取 IDAT 重封装 `sig + IHDR + acTL + [fcTL + IDAT/fdAT]×n + IEND`
   （acTL 必须在 IHDR 之后、首个 IDAT 之前），`dispose=NONE / blend=SOURCE` 整幅覆盖不叠影；
   时间轴与动作库存 localStorage（`traeEmoji.kf.v1` / `kfSaved.v1`）；调试入口 `__traeEmoji.kf`。

更详细的参数推导、踩坑记录与调试入口（`window.__traeEmoji`）见
[说明-README.md](04-表情生成器-emoji-generator/说明-README.md)。
